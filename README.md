# 🚀 Proyecto S1 - Aplicación Web F1  
**Autores:** Bastos Thomas, Santoyo Juan

## 📌 Descripción

Este proyecto es una aplicación web desarrollada con **JavaScript puro**, **HTML** y **CSS**, enfocada en la temática de la **Fórmula 1**. Para mejorar la experiencia del usuario, se crearon **APIs propias** que permiten una interfaz más dinámica e interactiva.

La aplicación ofrece una visualización intuitiva de información sobre la F1, con herramientas tanto para usuarios comunes como para administradores.


## ✅ Funcionalidades

- Navegación a través de pestañas para acceder a diferentes secciones.
- Visualización de información relacionada con la Fórmula 1.
- Panel de administración (solo visible para admins), con funciones de:
  - Crear nuevos registros de autos.
  - Editar información existente.
  - Eliminar registros.

## 🎯 Objetivos del Proyecto

- Aplicar los conocimientos adquiridos en JavaScript, HTML y CSS.
- Construir una interfaz dinámica mediante manipulación del DOM.
- Integrar APIs personalizadas para mostrar y gestionar datos.
- Crear una experiencia amigable e intuitiva para el usuario.
 ### Administrador:
**Crear** nuevos registros de autos.
**Editar** información existente.
- **Eliminar** registros innecesarios.

> ⚠️ Las funciones administrativas están protegidas y visibles solo para usuarios autorizados.
